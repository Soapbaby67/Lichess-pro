# Lichess Mobile Pro — Реальная интеграция с серверами Lichess, расширенная аналитика и кастомизация тем/фигур

Трансформация приложения из автономного демонстрационного стенда в полноценный клиент Lichess, напрямую связанный с серверами `https://lichess.org/api` через ваш личный токен Lichess API, с расчетом увеличенной статистики по вашим реальным партиям, запуском живых онлайн-игр, новыми дизайнами тем и фигур, а также готовым пакетом автоматической сборки APK для вашего Flutter-форка `Soapbaby67/mobile` и `Soapbaby67/Lichess-pro`.

## Согласованные решения

> [!IMPORTANT]
> Все ключевые архитектурные решения зафиксированы на основе ваших ответов:

- **Двойная поддержка (`Lichess-pro` + Flutter-форк `Soapbaby67/mobile`)**: Мы подключаем живой Lichess API непосредственно в текущее приложение (которое собирается в APK в репозитории `Lichess-pro`) и одновременно формируем готовый патч + GitHub Actions workflow для вашего Flutter-репозитория `Soapbaby67/mobile`.
- **Полная авторизация через токен Lichess API (`lip_...`)**: Прямой вход в ваш аккаунт Lichess с правами чтения профиля, истории партий и запуска онлайн-игр (`board:play`, `challenge:write`, `puzzle:read`). В окне входа предусмотрена кнопка быстрого создания токена на сайте `lichess.org` с уже проставленными галочками прав доступа.
- **Фокус на увеличенной статистике, QoL-фишках и кастомизации**: Главный упор сделан на глубокую аналитику ваших реальных партий с Lichess, новые цветовые темы досок, переключаемые наборы шахматных фигур (Piece Sets) и удобство управления.

## 1. Обзор и ключевые возможности

- **Что делает приложение**:
  1. **Авторизует ваш реальный аккаунт Lichess** по API-токену (`GET /api/account`), отображает ваш никнейм, текущие рейтинги во всех дисциплинах (Bullet, Blitz, Rapid, Classical, Puzzle) и статус онлайн.
  2. **Загружает и анализирует ваши настоящие партии с Lichess** (`GET /api/games/user/{username}` в потоковом формате NDJSON и `GET /api/user/{username}/rating-history`), автоматически вычисляя матрицу дебютов (ECO), «слепые зоны», тепловую карту затрат времени по ходам, распределение исходов партий (мат, сдача, флаг, ничья), винрейт за белых/черных и текущую форму («Streak & Form»).
  3. **Позволяет играть онлайн на серверах Lichess**: запуск живой партии против официального Stockfish на сервере Lichess (`POST /api/challenge/ai`) или поиск соперника (`POST /api/board/seek`), потоковое получение ходов (`GET /api/board/game/stream/{gameId}`) и отправка ваших ходов на сервер (`POST /api/board/game/{gameId}/move/{uci}`).
  4. **Предоставляет расширенную кастомизацию доски и фигур**: 6 тем оформления доски и 4 различных векторных набора шахматных фигур с настройкой прозрачности маркеров ходов, плавной полосой оценки (Eval Bar) и адаптивными часами.

## 2. Пользовательский опыт и визуальный дизайн

### Ключевые пользовательские сценарии (User Flows)
1. **Вход в аккаунт Lichess в 1 клик**:
   - В верхней панели пользователь нажимает **«Войти в Lichess API»**.
   - В модальном окне можно нажать ссылку **«Создать токен на Lichess.org в 1 клик»** (открывает страницу Lichess с предзаполненными правами `board:play`, `challenge:write`, `preference:read`), вставить токен `lip_...` и нажать **«Подключить аккаунт»**.
   - Приложение мгновенно проверяет токен на `https://lichess.org/api/account`, подгружает профиль, рейтинги и последние сыгранные партии пользователя.
2. **Увеличенная аналитика реальных партий**:
   - Как только аккаунт подключен, экран статистики пересчитывается по реальным играм пользователя (с кнопкой выбора выборки: 20, 50 или 100 последних партий, а также фильтром дисциплины Bullet / Blitz / Rapid / Classical).
   - Добавлен новый блок **«Расширенная сводка аккаунта»**: детальная разбивка побед и поражений по причине (Мат / Сдача / По времени / Стаalemate), сравнение точности и темпа за белых и за черных, пиковый и текущий рейтинг, а также таблица ваших реальных последних партий с кнопкой **«Открыть партию на доске анализа»**.
3. **Кастомизация тем доски и наборов фигур + QoL**:
   - **6 тем доски**: `OLED Minimalist`, `Slate Grey`, `Wood Classic`, `Emerald Tournament` (изумрудный турнирный), `Cyber Indigo` (глубокий индиго), `Amber Walnut` (теплый орех).
   - **4 набора шахматных фигур (Piece Sets)**:
     - `Neo-Staunton Pro` — сбалансированная современная турнирная классика.
     - `Alpha Minimalist` — чистые геометрические силуэты с высокой читаемостью на маленьких экранах.
     - `Imperial Crown` — детализированный классический стиль с выраженными коронами.
     - `OLED Contrast Edge` — высококонтрастный контурный стиль специально для True Dark `#121212` экранов.
   - **QoL-функции**: свайпы влево/вправо по доске для перемотки ходов, свайп вниз для панели быстрых действий (Сдаться, Предложить ничью, Флип доски), карточки «Один клик к перелому» в анализе, адаптивные часы (`< 30с` янтарное предупреждение, `< 10с` красная пульсация) и тактильный отклик.
4. **Живая онлайн-игра на сервере Lichess**:
   - Во вкладке **«Онлайн-игра и Доска QoL»** пользователь с подключенным токеном может выбрать уровень Stockfish (1–8) или контроль времени (`3+0`, `3+2`, `5+0`, `10+0`), цвет фигур и нажать **«Начать живую партию на Lichess»**.
   - Ходы передаются в реальном времени через потоковый NDJSON-стрим Lichess Board API.

### Визуальная система
- **Цветовая палитра (True Dark OLED)**:
  - `--background`: `#121212` (истинный черный для экономии заряда OLED-матриц).
  - `--surface`: `#1E1E1E` (структурные панели и карточки с тонкими границами `#2A2A2E`).
  - `--accent`: `#D97706` (янтарный акцент активных элементов) и семантические индикаторы `#10B981` (победа / пик формы), `#EF4444` (критический цейтнот / зевок).
- **Типографика**:
  - Заголовки и навигация: `Plus Jakarta Sans` (SemiBold/Bold).
  - Часы, рейтинги, сантипешки, ECO-коды и тайминги: `JetBrains Mono` со строгим выравниванием цифр (`tabular-nums`).

## 3. Ключевые продуктовые и технические решения

- **Решение 1: Прямая потоковая работа с Lichess API (`NDJSON` Stream) прямо с клиента**
  - *Выбранный подход*: Запросы к `https://lichess.org/api/*` выполняются с заголовком `Authorization: Bearer <token>` и `Accept: application/x-ndjson` напрямую из приложения (серверы Lichess официально поддерживают CORS для клиентских и мобильных приложений).
  - *Почему*: Это позволяет вашему скомпилированному `.apk` на телефоне работать напрямую с серверами `lichess.org` без промежуточного бэкенд-сервера.
- **Решение 2: Автоматический генератор патча и сборщик для Flutter-форка `Soapbaby67/mobile`**
  - *Выбранный подход*: Обновление как веб/Capacitor-репозитория `Soapbaby67/Lichess-pro`, так и подготовка готового `.github/workflows/build-flutter-apk.yml` + всех `.dart` модулей (`LichessOAuthRepository`, `RealGamesStatsAggregator`, `PieceSetThemeSelector`, `AdvancedStatsScreen`) для вашего Flutter-форка `Soapbaby67/mobile`.
  - *Почему*: Вы сможете собирать APK в облаке GitHub без ПК как из `Lichess-pro`, так и из официального Flutter-движка `Soapbaby67/mobile`.

### Интерактивные состояния и переходы
- **Состояние авторизации (`AuthState`)**: хранит токен в `localStorage`, автоматически подгружает профиль при запуске, отображает индикатор синхронизации партий (`Загружено N реальных партий с Lichess`) и позволяет в любой момент обновить список игр с сервера или переключиться на демо-данные при отсутствии сети.
- **Состояние кастомизации (`BoardCustomizationState`)**: мгновенно переключает тему доски (из 6 пресетов), набор фигур (из 4 векторных сетов) и прозрачность точек легальных ходов, сохраняя выбор пользователя между сессиями.
- **Состояние живой партии (`LiveLichessGameState`)**: подключается к потоку `/api/board/game/stream/{gameId}`, синхронизирует доску и адаптивные часы после каждого полухода и отправляет ходы игрока в формате UCI.
